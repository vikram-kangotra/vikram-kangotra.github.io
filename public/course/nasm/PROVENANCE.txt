worker.js is the course's own adapter. It invokes NASM in a disposable Web
Worker with an in-memory filesystem. The course's src/course/nasmCompiler.js
sets a 30-second timeout and terminates each worker after compilation. No
learner source is sent to a server. This editor builds a single 512-byte BIOS
boot sector; complete multi-file C kernels use the downloadable toolchain.
